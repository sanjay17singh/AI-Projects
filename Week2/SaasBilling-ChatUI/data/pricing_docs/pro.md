# Pro Plan

**$39/month** or **$468/year** (save ~17%).

Includes everything in Starter, plus:
- Up to 10 team seats
- 50,000 API calls / month included, overage billed at $0.002/call
- 50 GB storage
- Priority email + chat support (12-hour response time)
- Saved custom reports
- Basic integrations (Slack, webhooks)

Most popular plan for growing teams. Downgrading to Starter takes effect at the end of the current billing cycle by default.
