# Add-ons

Available on any paid plan, billed on the same cycle as your base plan:

- **Extra seat**: $8/seat/month (or $80/seat/year)
- **Extra storage block**: $5 per 50 GB/month
- **Extra API call block**: $10 per 25,000 calls/month
- **Priority onboarding session**: one-time $199 fee

Adding an add-on mid-cycle is prorated for the remaining days in the current period. Removing an add-on credits the unused prorated amount to your next invoice.
